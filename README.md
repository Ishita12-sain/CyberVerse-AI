# CyberVerse AI

Train for real-world challenges with AI-powered workplace simulations.

## Project Overview

CyberVerse AI is an AI-powered workplace simulation platform where users can practice real-world workplace scenarios, make decisions, receive scores, and get AI-powered coaching and feedback.

## Main Features

- User authentication
- Role/department selection
- Personalized dashboard
- AI-generated workplace scenarios
- Interactive missions
- Mission scoring
- AI coaching and explanations
- Progress tracking
- Admin analytics
- Department statistics
